# Python Scripts

A collection of Python scripts

| Name             | Description                                                                        |
| ---------------- | ---------------------------------------------------------------------------------- |
| firefox_tools    | Tools for Firefox (and Zen) : print permissions & search engines, vacuum profiles. |
| seek_and_destroy | Remove files/directories and stop processes that are listed.                       |
| utils            | utils library for the scripts, do not execute it                                   |

## How to run

```bash
uv run python -m _name_
```

Example

```bash
uv run python -m firefox_tools
```

Don't forget to use -h to see help

```bash
uv run python -m firefox_tools -h
```
