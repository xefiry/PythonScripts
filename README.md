# Python Scripts

A collection of Python scripts

| Name             | OS            | Description                                                              |
| ---------------- | ------------- | ------------------------------------------------------------------------ |
| firefox_tools    | Linux/Windows | Tools for Firefox : print permissions & search engines, vacuum profiles. |
| seek_and_destroy | Windows only  | Remove files/directories and stop processes that are listed.             |
| utils            | N/A           | utils library for the scripts, do not execute it                         |

## How to run

```bash
uv run python -m _name_
```

Example

```bash
uv run python -m firefox_tools
```

Don't forget to use -h to see help

```bash
uv run python -m firefox_tools -h
```
